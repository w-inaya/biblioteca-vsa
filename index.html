Vigilância Socioassistencial

Este site é uma criação pessoal de uma profissional da Vigilância Socioassistencial para facilitar a busca de alguns dados para produção de informações, sendo que há sites que precisam de perfil autorizado para acesso com login e senha e outros sites são todos de dados abertos. Existe a opção de abrir o link na página original, especialmente importante para aqueles que não permitem abrir direto neste site. Última atualização: 30 set 2026.

🔒 Acesso Restrito

Sistemas que exigem credenciais institucionais prévias (ex: CadSUAS, SAA, Prontuário SUAS, SISC e SIGPBF).

🌐 Dados Abertos

Portais públicos para consultas de indicadores socioeconômicos e demográficos (ex: IBGE, IPEA, DATASUS, CECAD e Atlas Brasil).
